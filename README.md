# Power BI Data Analysis Project

This project showcases a Power BI dashboard analyzing data on movies and TV shows from 2008 to 2021. The dataset contains information on total shows, directors, ratings, genres, and trends over the years.

## Key Highlights

- **Total Shows Analyzed:** 8,809
- **Unique Directors:** 4,527
- **Total Listed Categories:** 515
- **Year Range:** 2008 to 2021

## Visual Insights

### Ratings Distribution
- Visualized the number of shows across different ratings, such as:
  - TV-MA
  - TV-14
  - TV-PG
  - PG-13
  - TV-Y7
  - TV-Y
  - PG

### Genres Breakdown
- Top genres and categories include:
  - Dramas
  - Documentaries
  - Stand-Up Comedy
  - Children & Family

### Movie vs. TV Show Count
- **Movies:** 6,130 (69.6%)
- **TV Shows:** 2,680 (30.38%)

### Trends Over Time
- Explored how the number of shows has varied from 2008 to 2021.

## Technology Stack
- **Power BI Desktop:** Used for creating visualizations and analyzing the dataset.

## Map Visualization
- Integrated map view for geographical insights using:
  - Bing Maps
  - OpenStreetMap

## Usage
1. Open the Power BI file in **Power BI Desktop**.
2. Explore the different visualizations and filters available.
3. Analyze the trends, ratings, and category distribution for deeper insights.
